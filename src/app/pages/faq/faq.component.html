About this website

This site is dedicated for those Surviving Mars players that want to be able to locate a landing area of their preference. You can perform any filtering and sorting using the table tools and also display the landing location details such as topography, difficulty, breakthrough technologies, etc.

Source data

Specially thanks to ChoGGi for providing all the CSV files for each version of the game (including DLCs). You can find those in this GitHub repository.

How do I report a bug?
